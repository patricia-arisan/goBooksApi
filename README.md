# GoBooks

Este documento contiene la descripción de la aplicación GoBooks, sistema de gestión y seguimiento de catálogos literarios.


## Tecnologías utilizadas

* **Frontend:** Angular 19.2.12, TypeScript, Boostrap, Angular Material.
* **Backend:** Java 17, Spring Boot 3.4.4.
* **Almacenamiento:** MySQl 8.0.41, Redis 3.0.504.


## Estructura del repositorio

El proyecto está estructurado en dos directorios:
* `/backend`: API REST construida en Java y Spring Boot.
* `/frontend`: Interfaz gráfica de la aplicación realizada en Angular.
